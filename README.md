# My Business card

Has BLE, NFC and an I2C accelerometer.

This software uses the NFC for vCard, and to wake it up from low power mode. Tapping it or flicking it will wake it up too. Cool LED animations.

## Presenter remote

This also works as a BLE presenter remote, pressing ← and → keys and lighting up LEDs when flicking in either direction with the card facing up.
